# 鱼来（本地版）

渔获和环境记录。纯前端，数据只存在你自己的设备上。

## 放到 GitHub Pages

1. 在 GitHub 新建一个 **Public** 仓库，比如 `wharf-log`。
2. 仓库页面点 **Add file → Upload files**，把这个文件夹里的 6 个文件全部拖进去（`index.html`、`sw.js`、`manifest.webmanifest` 和 3 个图标要在仓库根目录，不要套一层文件夹），点 **Commit changes**。
3. **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`、目录 `/ (root)`，Save。
4. 等一两分钟，页面上方会出现地址：`https://你的用户名.github.io/fishing-log/`

## 装到手机

- iPhone：用 **Safari** 打开上面的地址 → 分享按钮 → **添加到主屏幕**。
- Android：用 Chrome 打开 → 菜单 → **添加到主屏幕 / 安装应用**。

之后从主屏幕图标进入。有信号时打开过一次以后，没信号也能用。

iPhone 上主屏幕应用和 Safari 的数据是分开存的，所以**先添加到主屏幕，再开始记录**。

## 水深（v2）

- “钓点”页给每个码头填一次水深（桩脚边、近、中、远）和底质。可以填海图上读的数，也可以选“现在实测”填铅坠量出来的数，会按当时潮高换算。
- 出钓时除了满潮、低潮时间，再填上两个潮高（潮汐表上有）。
- 之后每条鱼会按抛投位置和上钩时间自动算出当时的实际水深，统计页有“哪个水深出鱼”。

## 钓点位置（v2.1）

- 编辑钓点时可以“用当前位置”（人在码头上）或“在地图上选点”（卫星图上拖动十字对准），需要联网。
- 定了位置以后，“看海图水深”会直接打开 i-Boating 在线海图上这个码头的位置。

## v3：像素风界面和钓鱼博物志

- 浅黄底、木色顶栏底栏、直角像素边框；“今天”页的主角是一个像素潮汐圆盘：顶上满潮、底下低潮、顺时针走，指针是现在，圆盘里的水位是当前潮高，金色弧段是这次出钓的时段，红方块是渔获，月亮按当天月相画（南半球视角）。
- 新增“博物志”标签：Rozelle Bay 十种常见鱼，没钓到的是剪影，钓到第一条自动点亮；每种鱼有像素图版、辨认标注、习性、饵、NSW 法规和你自己的战绩。
- 法规数据核对于 2026 年 9 月（NSW DPIRD），规定会改，以官网为准。
- 钓点如果定位在海港大桥以西，出钓页会提示官方的食用建议：大桥以西的鱼和虾蟹不要吃。

## 数据

- “记录”页底部：**备份全部数据**（.json，换手机时用）、**导出 CSV**（做分析用）、**导入**（两种文件都认，重复的自动跳过）。
- 删掉主屏幕图标或清除浏览器数据会把记录一起清掉，隔一阵备份一次。
- 从 Claude 里的旧版搬数据：旧版“记录”页导出 CSV，在这里点导入。

## 更新

替换仓库里的 `index.html` 后，把 `sw.js` 第 2 行的版本号加一（`wharflog-v1` → `wharflog-v2`）。手机上联网重开两次应用就是新版，数据不受影响。
